# 📰 News Portal App

A **simple yet functional news portal application** built using **pure PHP** (no frameworks), designed to support multiple user roles with different permissions.

---

## 💡 Overview

This project is a fully functional news publishing platform with role-based access control and dynamic content rendering.  
It's designed with **security**, **clarity**, and **user management** in mind.

---

## 👥 User Roles

There are **four main roles**, each with specific privileges:

- **🧍 Normal User (without login)**:  
  - Can view all published news articles  
  - Can post comments on articles

- **✍️ Author**:  
  - Can create and submit news articles  
  - Can view the status of their submitted articles

- **🧾 Editor**:  
  - Can review, edit, and approve/reject submitted news from authors  
  - Has access to all news for moderation

- **🛠️ Admin** *(Singleton - only one account created once)*:  
  - Full control over user accounts  
  - Can add/edit/delete categories  
  - Manages platform-level settings and roles

---

## ⚙️ Features

- 🔐 **User Authentication and Role-Based Access Control**  
- 📄 **Dynamic News Pages**  
  - News displayed based on user role and category
- ✍️ **Commenting System**  
- 🗂️ **Category Management** (Admin only)
- 🧱 **No frameworks used** – built entirely in **pure PHP**
- 🛡️ **Security Measures**:  
  - Protection against **Cross-Site Scripting (XSS)**  
  - Protection against **SQL Injection**

---

## 🛠️ Technologies Used

- **Backend**: PHP (No frameworks)
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript (No Frameworks)

---

## 🔐 Security Highlights

- Input validation and sanitization across all forms
- Prepared statements for database queries
- Role-based access control for different parts of the system

---

## 📌 Status

This project is ideal for learning or demonstrating:
- Pure PHP application structure
- Role-based systems
- Security best practices in backend development
