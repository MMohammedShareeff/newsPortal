### News Portal App

**Simple news portal app with the following features:**
- **pure php project (no framwewoks).**
- **Multiple user accounts according to roles.**
- **There are four main roles:**
  - **Normal user**: can comment and view different news.
  - **Author**: can create news and view his added news with their status.
  - **Editor**: can review and edit all news and approve them.
  - **Admin**: one super admin account created once (Singleton pattern).
    Admin can control user accounts and add or edit categories.
- **Dynamic pages** that fetch content according to roles and categories.
- **Secured against** cross-site attacks and SQL injection.
